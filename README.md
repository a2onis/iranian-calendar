# گاه‌شمار ایرانی

**گاه‌شماری کهن ایران — دوازده ماهِ سی‌روزه، سی روزِ نام‌دار، پنجهٔ وهیک و جشن‌های کهن،
در یک صفحه و بدون اینترنت.**

برنامهٔ اندروید بومی با **Kotlin** و **Jetpack Compose**. تنها یک صفحه دارد: تقویم ایرانی.
روزی را برمی‌گزینید و جشن‌ها و آیین‌های همان روز را می‌بینید. نه نوار پایین، نه تب،
نه گاه‌شماری میلادی یا قمری.

| | |
|---|---|
| زبان | تمام‌فارسی، راست‌به‌چپ |
| گاه‌شماری | ایرانی کهن: ۱۲ ماه × ۳۰ روز + پنجهٔ وهیک |
| روزها | نام‌دار، از اورمزد تا انارام، با معنای هر نام |
| جشن‌ها | ۲۶ جشن، آیین و گاهنبار |
| پوسته | تیره به‌طور پیش‌فرض، روشن و «هماهنگ با سامانه» هم هست |
| اینترنت | هیچ — بدون مجوز `INTERNET` |
| اندروید | ۷ (API 24) و بالاتر |

## گاه‌شمار

این برنامه گاه‌شماریِ رسمیِ ۳۶۵ روزهٔ ایران را کنار نمی‌گذارد؛ همان نوروز نجومی را
نگه می‌دارد و ساختار کهنِ ایرانی را بر آن می‌نشاند:

* **سال** در لحظهٔ اعتدال بهاری به وقت تهران آغاز می‌شود. اگر اعتدال پیش از نیمروز باشد،
  همان روز یکم فروردین است؛ اگر پس از نیمروز، روز بعد. این همان قاعدهٔ مرکز تقویم
  مؤسسهٔ ژئوفیزیک دانشگاه تهران است و لحظه‌ها با الگوریتم نجومی مئوس و تصحیح ΔT
  حساب می‌شوند.
* **ماه**‌ها دوازده‌تا و همه **سی‌روزه**اند: فروردین، اردیبهشت، خرداد، تیر، امرداد،
  شهریور، مهر، آبان، آذر، دی، بهمن، سپندارمذ.
* هر **روز** نامی دارد: اورمزد، بهمن، اردیبهشت … مانتره سپند، انارام. نام هر روز با
  معنای آن همراه است («بهرام — پیروزی»).
* روزهای پایانی سال، **پنجهٔ وهیک** است: پنج روز گاتها (اهونود، اشتود، سپنتمد،
  وهوخشتر، وهیشتواشت) و در سال کبیسه شش روز.

چون ماه‌ها سی‌روزه‌اند، جشن‌های کهنِ «روز و ماه هم‌نام» هر سال در جای خود می‌افتند:

| جشن | روز |
|---|---|
| نوروز | ۱ فروردین |
| خردادروز (نوروز بزرگ) | ۶ فروردین |
| سیزده‌بدر | ۱۳ فروردین |
| فروردینگان | ۱۹ فروردین |
| اردیبهشتگان | ۳ اردیبهشت |
| خردادگان | ۶ خرداد |
| تیرگان | ۱۳ تیر |
| امردادگان | ۷ امرداد |
| شهریورگان | ۴ شهریور |
| مهرگان | ۱۶ مهر |
| آبانگان | ۱۰ آبان |
| آذرگان | ۹ آذر |
| دیگان (سه‌گانه) | ۸، ۱۵ و ۲۳ دی |
| بهمنگان | ۲ بهمن |
| سده | ۱۰ بهمن |
| سپندارمذگان | ۵ سپندارمذ |

و آن‌ها که به روزِ ماه وابسته نیستند: **چهارشنبه‌سوری** (آخرین چهارشنبهٔ پیش از نوروز)،
**یلدا** (روزی که انقلاب زمستانی در آن رخ می‌دهد) و **پنجهٔ وهیک**، به‌همراه
**پنج گاهنبار** سال (میدیوزرم، میدیوشم، پتیه‌شهیم، ایاثرم، میدیاریم).

## برنامه

* **یک صفحهٔ تمام‌صفحه** — بی تب و بی نوار پایین.
* تاریخ برگزیده با شمارهٔ روز، ماه، سال، نام روزِ هفته، **نام روز** و معنای آن.
* پیمایش روز به روز، سال به سال و پرش به هر یک از دوازده ماه.
* شبکهٔ روزهای ماه با نشانگر جشن‌ها؛ خانهٔ امروز و خانهٔ برگزیده جدا مشخص می‌شوند.
* **جشن‌های روز برگزیده** بی‌درنگ زیر تقویم می‌آیند؛ با یک ضربه، توضیح کوتاه هر جشن
  در برگهٔ پایین باز می‌شود.
* سه جشن پیشِ رو، با فاصلهٔ روزها.
* تنظیمات کوچک: پوسته (تیره/روشن/سامانه)، رقم‌های فارسی، یادآور روزانه.
* **یادآور روزانه** با اعلان محلی (بدون سرویس بیرونی).
* نقش‌مایه‌ها همه با Canvas کشیده شده‌اند: ستارهٔ هشت‌پر، آسمان شبانه، هالهٔ زر.

### رنگ‌ها

شبِ لاجوردی با متنِ استخوانی، زرِ آتشگاه، فیروزهٔ کاریز و گلِ انار. پوستهٔ تیره پیش‌فرض
است و کنتراست متن‌ها برای خوانایی تنظیم شده: متن اصلی حدود ۱۲:۱ و متن فرعی حدود ۷:۱.
پوستهٔ روشن کاغذِ کهن با متنِ جوهری است.

## پیش‌نمایش وب

پوشهٔ `preview/` همان برنامه در مرورگر است: همان داده، همان محاسبه، همان زبان بصری.
این پیش‌نمایش ابزار دیدن و آزمودن است و خودِ برنامهٔ اندروید نیست.

```bash
python3 -m http.server 8080 --directory preview
# http://localhost:8080
```

| فایل | کار |
|---|---|
| `preview/index.html` | پوستهٔ صفحه |
| `preview/style.css` | شیوه‌نامهٔ تیره و روشن |
| `preview/calendar.js` | موتور محاسبه (آینهٔ `core/` در کاتلین) |
| `preview/data.js` | جشن‌ها و نام‌های روز، ساختهٔ `tools/export_preview.py` |
| `preview/fonts/` | وزیرمتن و لاله‌زار |

دادهٔ پیش‌نمایش از دل کد کاتلین استخراج می‌شود؛ پس از هر تغییر در محتوا:

```bash
python3 tools/export_preview.py
```

## ساخت و نصب

گردش‌کار `.github/workflows/android.yml` با هر تغییر، آزمون‌ها را اجرا و APK را می‌سازد.
با هر برچسب نسخه (`v*`) همان APK به بخش **Releases** پیوست می‌شود.

```bash
git tag v2.0.0 && git push origin v2.0.0
```

روی رایانهٔ خودتان (JDK ۱۷ و Android SDK ۳۴):

```bash
gradle :app:assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
gradle :app:testDebugUnitTest
```
