# گاه‌شمار ایرانی

**گاه‌شماری کهن ایران — دوازده ماه با نام‌های اوستایی، سی روزِ نام‌دار، پنجهٔ وهیک و
جشن‌ها و آیین‌های کهن، در یک صفحه و بدون اینترنت.**

برنامهٔ اندروید بومی با **Kotlin** و **Jetpack Compose**. تنها یک صفحه دارد: تقویم ایرانی.
روزی را برمی‌گزینید و جشن‌ها و آیین‌های همان روز را می‌بینید. نه نوار پایین، نه تب،
نه گاه‌شماری میلادی یا قمری.

| | |
|---|---|
| زبان | تمام‌فارسی، راست‌به‌چپ |
| گاه‌شماری | ایرانی: همان تاریخ رسمی ایران (۳۱/۳۰/۲۹ روز) با نام‌های کهن |
| روزها | نام‌دار، از اورمزد تا انارام، با معنای هر نام |
| جشن‌ها | ۶۹ جشن، آیین، گاهنبار، اسطوره، تاج‌گذاری و یادبود |
| سال | پهلوی (۲۵۸۵)، نه هجری خورشیدی |
| قلم | وزیرمتن، در همهٔ برنامه |
| پوستهٔ فصلی | چهار رنگ‌مایه که با ماهِ ایرانی می‌گردد |
| پوسته | فصلی (پیش‌فرض)، تیره، روشن و هماهنگ با سامانه |
| اینترنت | هیچ — بدون مجوز `INTERNET` |
| اندروید | ۷ (API 24) و بالاتر |

## گاه‌شمار

این برنامه گاه‌شماریِ رسمیِ ۳۶۵ روزهٔ ایران را کنار نمی‌گذارد؛ همان نوروز نجومی را
نگه می‌دارد و ساختار کهنِ ایرانی را بر آن می‌نشاند:

* **سال** در لحظهٔ اعتدال بهاری به وقت تهران آغاز می‌شود. اگر اعتدال پیش از نیمروز باشد،
  همان روز یکم فروردین است؛ اگر پس از نیمروز، روز بعد. این همان قاعدهٔ مرکز تقویم
  مؤسسهٔ ژئوفیزیک دانشگاه تهران است و لحظه‌ها با الگوریتم نجومی مئوس و تصحیح ΔT
  حساب می‌شوند.
* **ماه**‌ها دوازده‌تا با نام‌های کهن‌اند: فروردین، اردیبهشت، خرداد، تیر، امرداد،
  شهریور، مهر، آبان، آذر، دی، بهمن، سپندارمذ. درازای آن‌ها همان درازای گاه‌شماری
  رسمی ایران است: شش ماه نخست ۳۱ روز، پنج ماه ۳۰ روز و سپندارمذ ۲۹ روز (۳۰ روز در
  سال کبیسه). پس تاریخِ هر روز، همان تاریخِ تقویم ایران است.
* هر **روز** نامی دارد: اورمزد، بهمن، اردیبهشت … مانتره سپند، انارام. نام هر روز با
  معنای آن همراه است («بهرام — پیروزی»). روز سی‌ویکم ماه‌های سی‌ویک‌روزه
  **«اَندَرگاه»** است، یعنی روزِ افزونِ ماه.
* روزهای پایانی سال، **پنجهٔ وهیک** است: پنج روز گاتها (اهونود، اشتود، سپنتمد،
  وهوخشتر، وهیشتواشت) از **۲۵ سپندارمذ**، و در سال کبیسه شش روز.

جشن‌های کهنِ «روز و ماه هم‌نام» هر سال در همان روز و ماه می‌افتند:

| جشن | روز |
|---|---|
| نوروز | ۱ فروردین |
| خردادروز (نوروز بزرگ) | ۶ فروردین |
| سیزده‌بدر | ۱۳ فروردین |
| فروردینگان | ۱۹ فروردین |
| اردیبهشتگان | ۳ اردیبهشت |
| خردادگان | ۶ خرداد |
| تیرگان | ۱۳ تیر |
| امردادگان | ۷ امرداد |
| شهریورگان | ۴ شهریور |
| مهرگان | ۱۶ مهر |
| آبانگان | ۱۰ آبان |
| آذرگان | ۹ آذر |
| دیگان (سه‌گانه) | ۸، ۱۵ و ۲۳ دی |
| بهمنگان | ۲ بهمن |
| سده | ۱۰ بهمن |
| سپندارمذگان | ۵ سپندارمذ |
| خرم‌روز (نخستین دیگان) | ۱ دی |
| سیرسور | ۱۴ دی |
| پایان مهرگان (رام‌روز) | ۲۱ مهر |
| میانهٔ پاییز | ۱۵ آبان |
| نوروز رودها | ۱۹ سپندارمذ |

و آن‌ها که به روزِ ماه وابسته نیستند: **چهارشنبه‌سوری** (آخرین چهارشنبهٔ پیش از نوروز)،
**یلدا** (روزی که انقلاب زمستانی در آن رخ می‌دهد) و **پنجهٔ وهیک**، به‌همراه
**پنج گاهنبار** سال (میدیوزرم، میدیوشم، پتیه‌شهیم، ایاثرم، میدیاریم).

**آیین‌های زرتشتی** نیز در همین گاه‌شمار جای دارند: خرم‌روز، سیرسور، سروشگان،
گیاه‌آوری، آبانگاه، آذر جشن، درامزینان، وخشنکام، نوروز رودها، زادروز و سالروز درگذشت
زرتشت و پنج گاهنبار.

**اسطوره‌های ایران** هم روز دارند: کیومرث، آرش کمانگیر، پهلوانان شاهنامه (رستم و سهراب و
سیاوش)، جمشید و فریدون و کاوه، به‌همراه آیین‌های زرتشتی چون زادروز زرتشت.

**تاج‌گذاری شاهان ایران** هم روزِ خود را دارد: تاج‌گذاری جمشید و فریدون در روایت‌های
ایرانی، و سالروز تاج‌گذاری احمدشاه (۳۰ تیر)، رضاشاه (۴ اردیبهشت)، نادرشاه (۱۸ اسفند)
و محمدرضاشاه (۴ آبان)، به‌همراه روز کوروش بزرگ (۷ آبان).

**یادبودهای فرهنگی** هم آمده‌اند: فردوسی، سعدی، حافظ، خیام، عطار، مولانا، نظامی، جامی،
رودکی، نیما یوشیج، شهریار، پروین اعتصامی، ابن‌سینا، رازی، ابوریحان بیرونی، خواجه نصیر
و پایان سرایش شاهنامه. هیچ مناسبت اسلامی در این گاه‌شمار نیست.

## برنامه

* **یک صفحهٔ تمام‌صفحه** — بی تب و بی نوار پایین. نوار ماه‌ها هنگام گشودن، ماهِ
  جاری را در ابتدای خود می‌آورد.
* تاریخ برگزیده با شمارهٔ روز، ماه، سال، نام روزِ هفته، **نام روز** و معنای آن.
* پیمایش روز به روز، سال به سال و پرش به هر یک از دوازده ماه.
* شبکهٔ روزهای ماه با نشانگر جشن‌ها؛ خانهٔ امروز و خانهٔ برگزیده جدا مشخص می‌شوند.
* **جشن‌های روز برگزیده** بی‌درنگ زیر تقویم می‌آیند؛ با یک ضربه، توضیح کوتاه هر جشن
  در برگهٔ پایین باز می‌شود.
* سه جشن پیشِ رو، با فاصلهٔ روزها.
* تنظیمات کوچک: پوستهٔ فصلی، تاریخ روی صفحه (جا و اندازه)، محافظ صفحه، رقم‌های فارسی.
* **برنامه هیچ اعلانی نمی‌سازد.** نه اعلانِ دائمی، نه نشان در نوار وضعیت، نه ردیفی در برگهٔ
  اعلان‌ها؛ بازماندهٔ اعلان‌های نسخه‌های پیشین هم یک‌بار و برای همیشه پاک می‌شود.
  (همان نشانِ ریزِ اعلان بود که بر صفحهٔ همیشه‌روشن، ناخوانا و ریز دیده می‌شد.)
* **تاریخ، تنها در نوار وضعیت — بی هیچ اعلانی.** متنِ تاریخ با پنجرهٔ روی‌هم‌افتادنی
  کشیده می‌شود، نه با اعلان؛ پس نه برگهٔ اعلان‌ها و نه صفحهٔ قفل چیزی از برنامه نشان
  نمی‌دهند. دو راه برای گرفتنِ همین یک نمایش:
  1. **سرویس دسترس‌پذیری** — پنجرهٔ `TYPE_ACCESSIBILITY_OVERLAY` از نوار وضعیت هم
     بالاتر می‌نشیند، پس متن دقیقاً *در* نوار، هم‌راستا با ساعت، دیده می‌شود.
  2. **مجوز نمایش روی برنامه‌ها** (`SYSTEM_ALERT_WINDOW`) — پنجرهٔ
     `TYPE_APPLICATION_OVERLAY`. این پنجره از نوار وضعیت پایین‌تر لایه‌بندی شده است،
     پس متن درست *زیرِ* نوار می‌آید.
* **جای دلخواه** — چپِ نوار، میانِ نوار، راستِ نوار، یا زیرِ نوار (چپ/راست).
* **صفحهٔ همیشه‌روشن (AOD)** — AOD را سامانه می‌کشد و هیچ برنامه‌ای بدون دسترسی ریشه
  نمی‌تواند بر آن بنویسد؛ سامانه آنجا از برنامه‌ها تنها نشانِ ریزِ اعلان را می‌پذیرد.
  نزدیک‌ترین جایگزین، **محافظ صفحهٔ** اندروید است که همین برنامه فراهم می‌کند: تاریخ با
  حروفِ بسیار درشت بر زمینهٔ سیاه («گاه‌شمار ایرانی — تاریخ درشت» در تنظیماتِ محافظ صفحه).
* **جا و اندازهٔ تاریخ** — هفت جایگاه (نوار وضعیت: چپ/میان/راست؛ زیر نوار: چپ/راست؛
  میانِ صفحه؛ پایینِ صفحه) و پنج اندازه (۲۰، ۲۸، ۳۶، ۴۸، ۶۴)؛ به‌علاوهٔ متن کوتاه
  («۸ آبان») یا کامل («دی به آذر ۸ آبان»)، نوشتنِ سال پهلوی، زمینهٔ نیم‌شفاف پشت متن و
  حالت «فقط هنگام قفل». اندازهٔ برگزیده همان‌جا با نمونه‌ای زنده نشان داده می‌شود.
* **تاریخ همیشه به‌روز** — تاریخ هر بار از نو از گاه‌شمار خوانده می‌شود (هیچ چیز
  ذخیره نمی‌شود) و با روشن‌شدن صفحه، بازشدن قفل، تغییر تاریخ/ساعت/منطقهٔ زمانی،
  هر ۲۰ ثانیه یک‌بار و هر بامداد تازه می‌گردد.
* **الگوی تاریخ** — «نام روز، شمارهٔ روز، نام ماه»: «دی به آذر ۹ آبان».
* نقش‌مایه‌ها همه با Canvas کشیده شده‌اند: ستارهٔ هشت‌پر، آسمان شبانه، هالهٔ زر.

### رنگ‌ها

پوستهٔ **فصلی** پیش‌فرض است و با **ماهِ برگزیده** می‌گردد؛ پس با گشتن در ماه‌ها رنگ‌مایه
بی‌درنگ عوض می‌شود.

| فصل | ماه‌ها | رنگ‌مایه | روشنایی |
|---|---|---|---|
| بهار | فروردین–خرداد | سبزِ سبزه و صورتیِ شکوفه | روشن |
| تابستان | تیر–شهریور | فیروزهٔ آب و زرِ خورشید | روشن |
| پاییز | مهر–آذر | نارنجیِ برگ و ارغوانِ انار | تیره |
| زمستان | دی–سپندارمذ | آبیِ یخ و نقرهٔ برف | تیره |

پوستهٔ تیره، روشن و «هماهنگ با سامانه» هم در تنظیمات هست. کنتراست متن‌ها برای خوانایی
تنظیم شده: متن اصلی حدود ۱۲:۱ و متن فرعی حدود ۷:۱.

آیکن برنامه، طرحِ «تقویم نوروزی» است: تقویمِ سرخ با نشانِ شیر و خورشید، سبزهٔ نوروزی و
شکوفه‌های بهاری.

## پیش‌نمایش وب

پوشهٔ `preview/` همان برنامه در مرورگر است: همان داده، همان محاسبه، همان زبان بصری.
این پیش‌نمایش ابزار دیدن و آزمودن است و خودِ برنامهٔ اندروید نیست.

```bash
python3 -m http.server 8080 --directory preview
# http://localhost:8080
```

| فایل | کار |
|---|---|
| `preview/index.html` | پوستهٔ صفحه |
| `preview/style.css` | شیوه‌نامهٔ تیره و روشن |
| `preview/calendar.js` | موتور محاسبه (آینهٔ `core/` در کاتلین) |
| `preview/data.js` | جشن‌ها و نام‌های روز، ساختهٔ `tools/export_preview.py` |
| `preview/fonts/` | وزیرمتن و لاله‌زار |

دادهٔ پیش‌نمایش از دل کد کاتلین استخراج می‌شود؛ پس از هر تغییر در محتوا:

```bash
python3 tools/export_preview.py
```

## ساخت و نصب

گردش‌کار `.github/workflows/android.yml` با هر تغییر، آزمون‌ها را اجرا و APK را می‌سازد.
با هر برچسب نسخه (`v*`) همان APK به بخش **Releases** پیوست می‌شود.

```bash
git tag v3.0.0 && git push origin v3.0.0
```

APK انتشار با **R8** کوچک و بهینه می‌شود (کد و منابع کاسته می‌شوند) و با کلید ثابتِ
`app/keystore/gahshomar-demo.p12` امضا می‌گردد تا نسخه‌های بعدی روی نسخهٔ نصب‌شده
به‌روزرسانی شوند. این کلید نمونه است؛ برای انتشار در فروشگاه کلید خودتان را بگذارید.

روی رایانهٔ خودتان (JDK ۱۷ و Android SDK ۳۴):

```bash
gradle :app:assembleRelease   # app/build/outputs/apk/release/app-release.apk
gradle :app:assembleDebug     # نسخهٔ آزمون
gradle :app:testDebugUnitTest
```

### سرعت

برنامه در آغاز تنها همان صفحهٔ تقویم را می‌سازد؛ پنجرهٔ تاریخ به‌دست
سرویس دسترس‌پذیری و بیرون از روند برنامه ساخته می‌شود. محاسبهٔ روزِ سال بی‌تخصیص و جشن‌های هر سال یک‌بار
محاسبه و در حافظه نگه داشته می‌شوند. نسخهٔ انتشار با R8 کد و منابع را می‌کاهد.
